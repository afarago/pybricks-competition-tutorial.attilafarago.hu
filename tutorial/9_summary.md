# Sample competition code
You can find a sample competition code in my github repository: [2025 EduCup Masters - Attila Faragó](https://github.com/afarago/2025educup-masters-attilafarago).

## Tasks
Challenge: Simulate a space rescue mission for a stranded astronaut crew.

1. Build a Spaceship: Assemble Lego components to create a functional spaceship.
2. Collect Cargo: Gather essential supplies (water, air, food) for the astronauts.
3. Rescue the Crew: Guide the astronaut Lego figures to a safe location.
4. Park the Robot: Guide the robot to a designated parking area.

Scoring: Points are awarded for completing each task, with bonuses for efficiency and correct spaceship assembly.

## Robot actions

The robot navigates, collects and releases objects, and aligns itself with walls using sensors and motor control.

Here's a breakdown of the robot's actions:

1. Initialization: The robot configures its motors, sensors, and settings. It defines functions for basic movements like turning, moving forward, and raising/lowering an arm.
1. Part 1: The robot starts at a specific orientation facing south. It moves and turns to reach the North Wall, collects an object (R2), and then places it on another object (R1) while aligning itself with the East Wall.
1. Part 2: The robot collects another object (R1) and places it on a designated spot.
1. Part 3: The robot collects a third object (R3) and prepares to place it with other objects.
1. Part 4: The robot gathers additional objects (R3, Fig3, Fig4, and a soda can) and places them strategically.
1. Part 5: The robot collects a soda can and places it near a rocket.
1. Part 6: The robot retrieves objects (Fig1, Fig2) and releases them.
1. Part 7: The robot takes a soda can to a designated university

The robot uses a combination of movement, object manipulation, and wall-following strategies to execute these tasks efficiently.
